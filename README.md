# web-snapshot-batch

Created by OKIHIRO — AI自動化ワークフローを100個以上開発・運用しています。

`web-snapshot-batch` は、複数URLからPC/モバイルのスクリーンショット、HTML、本文テキスト、CSSを一括保存するAIエージェント向けスキルです。

## 何ができるか

- 複数URLの一括撮影
- PC/モバイル両方のスクリーンショット保存
- HTML、本文テキスト、CSSの保存
- 実行サマリの生成

## 注意

- 外部APIキーは不要です。
- 対象Webサイトへアクセスするためのネットワーク接続が必要です。
- 初回にPlaywright Chromiumのインストールが必要です。
